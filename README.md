# PIXELRADIO-Project
A pixel-art inspired online radio experience featuring cozy environments and ambient music.
## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, and responsive web design
- **JavaScript** – Interactive features and application functionality
- **Web Design** – UI/UX design and visual development
- **Cloudflare Workers** – Deployment and hosting of the website
